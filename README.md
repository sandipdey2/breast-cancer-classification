# Breast Cancer Diagnosis Classification

Supervised binary classification of breast tumors (malignant vs benign) using Logistic Regression on the Breast Cancer Wisconsin (Diagnostic) dataset.

**GitHub Repository:** https://github.com/sandipdey2/breast-cancer-classification

## Dataset
- **Name:** Breast Cancer Wisconsin (Diagnostic)
- **Source:** https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
- **Size:** 569 samples, 30 numeric features + diagnosis label

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/sandipdey2/breast-cancer-classification.git
   cd breast-cancer-classification
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Place `breast_cancer.csv` in the same folder as the notebook.
4. Open and run `modeling.ipynb` top to bottom.

## Files
- `modeling.ipynb` – complete machine learning workflow
- `module_summary.pdf` – analysis report with citations
- `requirements.txt` – environment for reproducibility
- `breast_cancer.csv` – dataset (include if not already present)
